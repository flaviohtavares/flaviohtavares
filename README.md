# Hi, I'm Flavio 👋

I'm the founder of **[Tavlabs Ltd](https://www.tavlabs.uk/?utm_source=github&utm_medium=profile)**, a London software house for small and medium businesses.

Before writing software I spent 15 years in UK food manufacturing, importing and logistics, on the factory floor and on the road. Now I build software for the kind of operations I used to run: records that survive an audit, traceability, proof of delivery, and the paperwork nobody has time for.

## Projects

- **[UK Law](https://github.com/flaviohtavares/uk-law)**: all UK legislation (about 130,000 Acts and regulations) as plain Markdown, converted from legislation.gov.uk and updated every day, with an index and topic pages built for people and for AI assistants.
- **[UK Law tools](https://github.com/flaviohtavares/uk-law-tools)**: a Claude Code plugin and agent skill that lets Claude, Codex and other assistants look up UK law and answer with the exact section and the official link.
- **[Bindrik](https://github.com/flaviohtavares/bindrik-releases)**: a macOS app that assembles books for Amazon KDP.
- **Food safety pack**: a HACCP plan, allergen matrix and daily records written for a UK food business's actual menu. [See what you get](https://www.tavlabs.uk/?utm_source=github&utm_medium=profile).
